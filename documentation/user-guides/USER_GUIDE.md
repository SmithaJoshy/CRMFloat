## Client Management

### Adding a New Client

1. Click **"Clients"** in the navigation menu
2. Click **"Add Client"** button
3. Fill in client details:
   - **Name** (Required)
   - **Email** (Required)
   - **Phone** (Required)
   - Company
   - Address
   - Target Budget
   - Source (How they found you)
   - Notes
4. Click **"Save"**

### Viewing Client Details

1. Go to **Clients** page
2. Click on any client name
3. View complete client information:
   - Contact details
   - Project history
   - Documents
   - Communication logs

### Editing Client Information

1. Find the client in the list
2. Click the **menu icon (⋮)** next to their name
3. Select **"Edit"**
4. Update information
5. Click **"Save"**

### Client Search & Filters

- Use the **search bar** to find clients by name, email, or company
- Filter by **status** (Active, Inactive, Prospect)
- Sort by date, name, or budget

## Project Management

### Creating a New Project

1. Navigate to **Pipeline** or **Kanban**
2. Click **"Add Project"**
3. Fill in project details:
   - **Project Name** (Required)
   - **Client** (Select from dropdown)
   - **Project Value** (Required)
   - **Priority Level** (Low, Medium, High, Urgent)
   - **Assigned Designer**
   - **Property Type**
   - **Location**
   - **Size**
   - **Expected Completion Date**
4. Click **"Create Project"**

### Project Stages

Projects progress through these stages:
1. **ToDo** - New projects ready to start
2. **In Progress** - Active work
3. **Blocked** - Waiting for client or resources
4. **Paused** - Temporarily on hold
5. **Done** - Completed projects
6. **Canceled** - Discontinued projects

### Viewing Project Details

1. Click on any project name
2. View comprehensive information:
   - Client details
   - Project timeline
   - Team assignment
   - Budget and payments
   - Documents
   - Notes history

### Editing Projects

1. Open project details
2. Click **"Edit Project"**
3. Update information
4. For quick updates, use:
   - **Status change** - Update project stage
   - **Add notes** - Document changes or updates
5. Click **"Save"**

### Project Notes

Keep track of project updates:
- All notes are saved with timestamp
- Shows who added the note
- Notes are categorized (General, Status Change, Design Change, etc.)
- Complete history is preserved

## Workflow Pipeline

The Workflow Pipeline provides a visual representation of your project flow.

### Understanding the Pipeline

**Stages:**
- **Lead Generation** - New leads and prospects
- **Initial Engagement** - First client contact
- **Scheduling Visit** - Site visits planned
- **Consultation & Data Capture** - Requirements gathering
- **Design Brief & Proposal** - Proposal creation
- **Design Development** - Active design work
- **Detailed Drawings** - Technical drawings
- **Project Execution** - Implementation phase
- **Handover** - Project delivery
- **Project Closure** - Final completion

### Filtering Projects

1. Click on any **stage chip** at the top
2. View only projects in that stage
3. Click **"All Items"** to see everything
4. Use **search bar** for specific projects

### Stage Actions

- **View Details** - See complete project information
- **Edit** - Update project details
- **Move to Next Stage** - Progress the project

## Kanban Board

The Kanban board provides a drag-and-drop interface for project management.

### Board Layout

**Columns:**
- **ToDo** - Planned work
- **In Progress** - Current projects
- **Blocked** - Projects with blockers
- **Paused** - Temporarily on hold
- **Done** - Completed work
- **Canceled** - Discontinued projects

### Using the Kanban Board

**Drag & Drop:**
1. Click and hold a project card
2. Drag to the desired column
3. Release to update status

**Quick Actions:**
- **View Details** - Click card to see full information
- **Edit** - Use edit icon for status and notes updates
- **Filter** - Search for specific projects

### Project Cards

Each card shows:
- Project name
- Client name
- Project value
- Priority indicator
- Assigned designer

## Designer Management

### Adding Designers

1. Go to **Designers** page
2. Click **"Add Designer"**
3. Enter information:
   - **Name** (Required)
   - **Email** (Required)
   - **Phone** (Required)
   - **Role** (Required)
   - **Department**
   - **Skills**
   - **Experience**
   - **Specializations**
   - **Availability**
4. Enable **SMS** and **Email** notifications
5. Click **"Create Designer"**

### Designer Availability

Track designer workload:
- **Available** - Ready for new projects
- **Busy** - At capacity
- **Away** - Out of office
- **Unavailable** - Not taking projects

### Communicating with Designers

1. Find designer in the list
2. Click **menu icon (⋮)**
3. Choose:
   - **Send Email** - Opens email dialog
   - **Send SMS** - Sends text message
   - **View Projects** - See assigned projects

## Beyond Care

Beyond Care helps maintain relationships with valued customers.

### Valued Customer Features

**Identify Valued Customers:**
- Customers with multiple projects
- High-value clients
- Excellent feedback ratings

### Managing Testimonials

1. Go to **Beyond Care > Testimonials** tab
2. Select a **customer**
3. Click **"Add Testimonial"**
4. Fill in:
   - Project name
   - Rating (1-5 stars)
   - Review text
   - Public/private toggle
5. Click **"Add Testimonial"**

### Project Media

Showcase completed work:
1. Go to **Beyond Care > Project Media** tab
2. Select a **customer**
3. Click **"Add Media"**
4. Provide:
   - Project name
   - Media type (Photo, Video, Document)
   - Caption
   - Media URL
   - Public/private setting

### Rewards & Referrals

Incentivize repeat business:
1. Go to **Beyond Care > Rewards** tab
2. Select a **customer**
3. Click **"Add Reward"**
4. Enter:
   - Reward type
   - Title
   - Description
   - Value (₹)
   - Status

### Follow-up Schedule

Never miss a follow-up:
- View next follow-up dates
- Schedule new follow-ups
- Track customer anniversaries
- Automate reminders

## Documents & Files

### Uploading Documents

1. Navigate to **Documents** page
2. Click **"Upload Document"**
3. Select:
   - File to upload (Max 10MB)
   - Related client (optional)
   - Related project (optional)
   - Description
4. Click **"Upload"**

### Viewing Documents

- Browse all documents in list view
- Filter by client or project
- Download files as needed
- View upload date and uploader

### Document Organization

Documents are automatically organized by:
- Client
- Project
- Upload date
- File type

## Invoices & Payments

### Creating Invoices

1. Go to **Invoices** page
2. Click **"Create Invoice"**
3. Fill in:
   - **Invoice Number**
   - **Project** (Select from dropdown)
   - **Client** (Auto-populated from project)
   - **Amount**
   - **Due Date**
   - **Payment Status**
   - **Payment Terms**
   - **Notes**
4. Click **"Create Invoice"**

### Recording Payments

1. Go to **Payments** page
2. Click **"Record Payment"**
3. Enter:
   - **Client** (Select from dropdown)
   - **Project** (Select from dropdown)
   - **Amount**
   - **Payment Date**
   - **Payment Method**
   - **Reference Number**
   - **Notes**
4. Click **"Save"**

### Payment Tracking

Monitor payments:
- View all payment history
- Filter by client or project
- Track payment status
- Generate payment reports

### Sending Payment Reminders

1. Find overdue invoice
2. Click **"Send Reminder"**
3. System opens email client with pre-written message
4. Send reminder to client

## Troubleshooting

### Common Issues

**Can't log in?**
- Check your email and password
- Clear browser cache and cookies
- Try a different browser
- Contact your administrator

**Project not updating?**
- Refresh the page
- Check your internet connection
- Verify you have edit permissions
- Check browser console for errors

**Files won't upload?**
- Check file size (max 10MB)
- Verify file format is supported
- Try a different file
- Clear browser cache

**Drag & drop not working?**
- Refresh the page
- Try clicking edit instead
- Update your browser
- Check if JavaScript is enabled
